# PerlinNoise.js

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

PerlinNoise.js is a collection of Perlin noise generators for 1D, 2D, and 3D implementations.

## Demo
- [PerlinNoise1D DEMO](https://code4fukui.github.io/PerlinNoise/1d.html)
- [PerlinNoise2D DEMO](https://code4fukui.github.io/PerlinNoise/2d.html)
- [PerlinNoise3D DEMO](https://code4fukui.github.io/PerlinNoise/3d.html)

## Features
- Perlin noise generators for 1D, 2D, and 3D
- Smooth noise generation
- Customizable parameters

## Requirements
None

## Usage
To use the Perlin noise generators, import the respective classes:

```javascript
import { PerlinNoise1D } from './PerlinNoise1D.js';
import { PerlinNoise2D } from './PerlinNoise2D.js';
import { PerlinNoise3D } from './PerlinNoise3D.js';
```

Then, create an instance of the desired generator and use the `noise()` method to generate Perlin noise.
